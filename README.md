# Ray / Dev — Portfolio

A responsive, single-page developer portfolio built with plain HTML, CSS and vanilla JavaScript.

## Open in VS Code
1. Extract `ray-portfolio.zip`.
2. Open the extracted `ray-portfolio` folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.

## Before publishing
Update the contact details in `index.html`:
- Replace `ray@example.com` with your email address.
- Replace `27000000000` in the WhatsApp URL with your number in international format (South Africa: `27` followed by the number without the first `0`).
- Update the visible contact footnote to match.

The three portfolio items are clearly labelled concept projects, not completed client work. Replace them with your own projects as you build them.

## Files
- `index.html` — page structure and content
- `style.css` — theme, layout, responsive styles and animations
- `script.js` — mobile menu, scroll reveals and footer year

No frameworks or build tools are required. Google Fonts is loaded online; system sans-serif fallbacks are included.
